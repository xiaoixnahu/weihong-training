公司介绍

四川省味弘食品有限公司

始创于1986年，是一家集研发、生产、销售于一体的现代化食品企业，专注于高品质泡菜与调味品的塑造。 旗下拥有"川南"、"味聚特"两大品牌，产品畅销全国并远销日本、韩国、美国、欧盟等全球四十多个国家和地区。

近40年历程 无防腐剂 非转基因

企业价值观

  • 修身"五不原则"：不做假、不掩饰、不乱说、不拖延、不逃避
  • 齐家"三个第一"：客户第一、制度第一、执行第一
  • 七准则：超出预期、先向内看、从我做起、与人向上、做成事并对结果负责、长期持续成长、从战略来看当下
  • 三相互：相互信任、相互帮助、相互成就

入职当天指南

基本制度

《基本行为管理》（2311）

规范员工日常行为，营造简单直接、责任清晰的企业文化。

  • 基本价值观："不做假、不掩饰、不乱说、不逃避、不拖延"
  • 三项基本原则（违反任意一项视为严重违纪）：
    • 单向企业：禁止服务其他企业获取报酬、禁止向合作方索取利益、禁止泄露经营管理资讯
    • 行为真实：禁止财务虚报、造假报表、隐瞒事故、谎报信息
    • 职业操守：禁止偷盗打架、造谣破坏、管理者为亲友提供便利
  • 十项行为准则与十五项效能原则详见制度全文

《基本组织管理》（2510）

明确组织架构与汇报关系，确保高效协作。

  • 基础构建：以"战略实现"为导向，打赢"战略战役"，达成"业务流"绩效
  • 组织体系：营销体系、营运及生产体系、技术品质体系、人事体系、财务体系、保障体系、风控体系
  • 管理层级：治理层 | 经营层 | 管理层 | 执行层
  • 组织结构：岗位（专员/直线主管）→ 单元|项目（项目主管/单元主任）→ 部门

通用制度

《组织体系管理》（2601）

组织体系的设计、运行与优化管理。

  • 治理层：董事会
  • 经营层：设立战略总经理、食品安全总经理、安全总经理
  • 总监层：营销总监、技术品质总监、营运及生产总监
  • 战略总经理负责经营战略与业绩；食品安全总经理负责品质与食品安全；安全总经理负责生产与安全

《组织职能管理》（2510）

各部门职能定义与职责边界划分。

  • 职能构建：以"项目|单元"为基本组织单位，定义职能并落地于岗位
  • 职能行动环：设想 → 求证 → 计划 → 推行 → 追踪 → 优化 → 成果化
  • 职能落地：惯例职能 + 定义职能 + 拓展职能，形成【岗位动作表】
  • 七大体系：营销、营运及生产、技术品质、人事、财务、保障、风控

《职能岗位工作日管理制度》（2401）

工作时间、考勤与日常办公规范。

  • 夏季作息（5-9月）：上午 8:30-12:00，下午 13:30-18:00
  • 冬季作息（10-4月）：上午 8:30-12:00，下午 13:00-17:30
  • 工作日模式：A.周休制（周一至周五） B.月休制（月休4天） C.不定时工时制（部门负责人）
  • 考勤打卡：每日打卡三次（上午上班、下午上班、下午下班）
  • 请假：通过钉钉提报，未办理手续以旷工论处
  • 迟到/早退：3次或3天以上视为严重违纪，予以开除

《职能岗位-人员激励管理》（2401）

薪酬、绩效与员工激励机制。

  • 企业文化："肩膀者（看我的）"文化、"支持者（让我来）"文化
  • 职级设定：学习级 → 经验级 → 示范级 → 辅导级 → 教练级 → 战略级 → 经营级 → 卓越级
  • 职位设定：员工 → 主管主任 → 经理 → 总监
  • 薪酬构成：月基础工资 + 岗位工资 + 季管理工资，与工龄、职级系数、工作目标关联
  • 奖励机制：敬业奖、肩膀奖、支持奖

《食堂就餐管理制度》（2505）

食堂就餐时间、秩序与卫生规范。

  • 早餐（6:30-8:20）：包子/馒头、鸡蛋、稀饭、面条，补助10元
  • 午餐（11:40/12:00两批）：荤菜、素菜，多种菜品，补助20元
  • 晚餐（17:30-19:00）：补助15元
  • 夜宵（19:30-19:50）：限车间夜班人员，需提前上报人数
  • 就餐规定：人脸识别取菜、禁止插队、禁止食物外带、禁止浪费（违规罚款50元/次）
  • 着装要求：禁止穿拖鞋、超短裤、背心、赤膊等不文明着装

食品安全与卫生规范

  • 进入生产区域必须穿戴整洁的工作服、工作帽和口罩
  • 操作前必须洗手消毒，保持个人卫生
  • 严禁在生产区域饮食、吸烟或存放个人物品
  • 发现食品安全隐患须立即上报，不得隐瞒
  • 严格按照工艺流程操作，确保产品质量安全

车间/厂区安全须知

  • 进入车间须佩戴安全帽（指定区域）和防滑鞋
  • 熟悉消防器材位置及紧急疏散路线
  • 操作设备前须接受培训并获得授权
  • 发现设备异常立即停机并报告
  • 遵守用电安全规范，禁止私拉乱接

企业文化与团队融入

  • 主动沟通：遇到问题及时与导师、同事交流
  • 积极参与：参加部门会议和团队活动
  • 虚心学习：多观察、多请教、多记录
  • 融入文化：理解并践行"五不原则""三个第一"
  • 建立关系：与各部门同事建立良好协作关系
