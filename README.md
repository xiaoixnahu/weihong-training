# 味弘食品新人培训带教系统

味弘食品新人培训带教系统 - 网页版单页应用

## 访问地址

部署后访问：https://xiaoixnahu.github.io/weihong-training/

## 功能模块

1. **入职前** - 了解公司，做好准备
2. **入职当天** - 报到流程，制度学习
3. **在岗培养中** - 闯关模式，成长记录
4. **转正考核啦** - 填写考核，庆祝转正

## 技术说明

- 纯前端单页应用（SPA）
- localStorage 数据持久化
- 响应式设计，支持手机/电脑访问
- 无需后端服务器

## 部署方式

本仓库使用 GitHub Pages 托管，推送代码后自动部署。
